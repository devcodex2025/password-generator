## Fixed this pass

1. **Localized titles truncated mid-phrase** (`src/lib/home-metadata.ts`).
   `TITLE_BASE_MAX=35` cut keyword phrases at word boundaries producing titles
   like "Secure Password Generator – Create | generatepasswordto.me".
   Replaced with keyword-first bases <=35 chars for en/ua/es/fr/de/it/pt/ru/pl/
   ja; zh/ja already fit. Verified in build output:
   en → "Free Secure Password Generator | generatepasswordto.me" (55),
   ua → "Генератор паролів онлайн | generatepasswordto.me" (48).
2. **UA meta description truncated to a dangling preposition** ("…локально у").
   ua was the only locale over META_DESCRIPTION_MAX (156/155). Shortened to 146
   chars, complete sentence.
3. **llms.txt missing** → added `public/llms.txt` (site summary, key URLs,
   privacy/NIST/HIBP facts, affiliate disclosure) for AI crawler GEO.
4. **FAQPage JSON-LD included a question never visible on page**
   ("When was this FAQ reviewed?") — violates Google's content-parity rule for
   FAQ markup. Added the review Q&A card to `SeoAccordion.jsx` `getTrustFaq`
   (keys existed for all 11 locales).
5. **`next/script` JSON-LD on home** (`HomeStructuredData.tsx`) — source of the
   /en dev "script tag" warning. Rewritten to plain server-rendered
   `<script type="application/ld+json">` (same pattern as guides/comparison).
   JSON-LD now identical in SSR HTML for crawlers; warning gone.

## Recommendations (not done in this pass)

1. **Sitemap lastmod per-entity instead of build time**: next-sitemap stamps
   every URL with the build timestamp, so lastmod is noise. Consider per-article
   updatedAt for guides (lastmod quality signal).
2. **Server-side SSR for FAQ accordion**: SeoAccordion + other SEO text on home
   load with `ssr:false` — visible to Google after JS render, but JS-less AI
   crawlers may miss it. Moving to SSR (radix accordion is SSR-capable) is the
   highest-value GEO follow-up.
3. **`<html lang="en">` server-side for all locales**: HtmlLangSync patches lang
   after hydration only. Full fix = proxy rewrite of `/`→`/en` + pass-through
   root layout with html/body in `[locale]/layout` (next-intl pattern).
   Medium-risk refactor; defer until DNS is attached.
4. **GEO**: add localized llms.txt variants later; current English-only file is
   the standard first step.
