## Що змінено

### P1. Логотип у темній темі

- Логотип і далі використовує той самий `public/images/logo.svg` з тією ж геометрією.
- Світлу плашку під логотипом прибрано на вимогу власника: у хедері й футері логотип має прозорий фон в обох темах.
- Розміри хедера, футера та логотипа не змінюються під час перемикання теми.

**Відоме обмеження:** у темній темі контраст темно-синього напису `#2A4E63` на фоні `#121212` становить приблизно **2.11:1**, тобто нижче за WCAG 1.4.3. Це свідоме рішення після відмови від світлої плашки.

### P2. React-попередження про `<script>`

- `src/components/seo/HomeStructuredData.tsx` більше не повертає React-елементи `<script>`.
- JSON-LD серіалізується в один HTML-рядок і вставляється через `dangerouslySetInnerHTML` у прихований контейнер. Це зберігає `<script type="application/ld+json">` у серверному HTML, але React під час клієнтських переходів не створює script-елемент і не попереджає.
- Символ `<` у JSON екранується як `\u003c`, щоб значення не могло закрити script-тег.

**Ручна перевірка (dev і production build):**

- перехід `ua → en → ua` через селект мови: попередження `Encountered a script tag while rendering React component` відсутнє;
- на `/` і `/ua` у HTML присутні 6 JSON-LD блоків;
- усі 6 блоків успішно парсяться як JSON;
- після клієнтської навігації кількість блоків не зменшується (6 → 6);
- hydration mismatch не спостерігався.

Локальний production-сервер додатково показує 404 для `/_vercel/insights/script.js` і `/_vercel/speed-insights/script.js` — це особливість локального запуску Vercel Analytics, не пов'язана з цими змінами.

### P3. Попередження Next/Image для банера NordPass

- `AffiliateBanner` тепер рендерить креатив у контейнері з `aspect-ratio: width / height` і використовує `Image fill` + `object-contain`.
- Пропорції задає контейнер, а не атрибути зображення, тому попередження про змінений лише один вимір не виникає.
- Компонент використовується і на головній, і в статтях, тому виправлення покриває обидва місця.

**Ручна перевірка:**

- попередження Next/Image для `/affiliate/nordpass-en-728x90.png` відсутнє в dev і production;
- співвідношення сторін контейнера становить `728 / 90` (`8.089`), зображення заповнює його з `object-fit: contain`;
- на мобільних контейнер розтягується на 100% ширини з тим самим співвідношенням, на десктопі обмежений `max-w-3xl`;
- окремої анімації/стрибка під час завантаження немає, оскільки висота контейнера зарезервована через `aspect-ratio`.
